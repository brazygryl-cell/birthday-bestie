# Birthday card for my bestie 💗

A mobile-friendly interactive birthday card, featuring four personal photos, a heartfelt note, and a confetti surprise.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository (suggested name: `birthday-bestie`).
2. Upload `index.html` and the `photos` folder (maintain the paths).
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your page should appear at `https://YOUR-USERNAME.github.io/birthday-bestie/` after GitHub finishes publishing.

**Privacy:** A public GitHub Pages website makes these photos and message public. Only publish if you're comfortable sharing them.

To personalize the card, edit the message inside the `<section class="letter">` of `index.html`.
